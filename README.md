# ✈️ Sky Runner

Um jogo 2D desenvolvido com **HTML, CSS e JavaScript**, no qual o jogador controla um avião e precisa desviar de obstáculos enquanto tenta alcançar a maior pontuação possível.

## 🎮 Sobre o projeto

O Sky Runner é um jogo desenvolvido para praticar conceitos de desenvolvimento web, utilizando HTML Canvas para a renderização dos elementos e JavaScript para implementar a lógica e as mecânicas do jogo.

O objetivo é controlar o avião, evitar colisões com os obstáculos e acumular pontos para alcançar a maior pontuação possível.

## 🚀 Funcionalidades

- Controle do avião pelo teclado.
- Movimentação vertical.
- Geração aleatória de obstáculos.
- Detecção de colisões.
- Sistema de pontuação.
- Aumento gradual da dificuldade.
- Cenário com nuvens em movimento.
- Opção de reiniciar a partida.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## 🎯 Controles

| Tecla | Ação |
|:---:|---|
| ⬆️ | Mover o avião para cima |
| ⬇️ | Mover o avião para baixo |

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/sky-runner.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd sky-runner
   ```

3. Abra o arquivo `index.html` no navegador.

4. Clique em **Iniciar Jogo** para começar a jogar.

## 📌 Objetivo de aprendizagem

Este projeto tem como objetivo praticar conhecimentos de desenvolvimento web, incluindo manipulação do DOM, eventos de teclado, funções, estruturas de repetição, condicionais, arrays e utilização do Canvas.
